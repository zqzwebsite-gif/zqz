# راهنمای ساخت و دریافت فایل APK برای کوتاه کننده لینک ZQZ

این بسته شامل تمامی فایل‌های لازم برای تبدیل وب‌سایت **https://zqz.ir** به یک اپلیکیشن موبایل استاندارد PWA و فایل نصبی اندروید (APK) می‌باشد.

---

## 🚀 روش ۱: دریافت ۱ کلیکه و آنلاین فایل نصبی APK (سریع‌ترین روش)
بدون نیاز به نصب نرم‌افزارهای سنگین، با استفاده از ابزار رسمی و ابری PWABuilder:
1. وارد نشانی زیر شوید:
   https://www.pwabuilder.com/reportcard?url=https%3A%2F%2Fzqz.ir
2. روی دکمه **Package for Stores** و سپس **Android** کلیک کنید.
3. فایل نصبی **.apk** امضا شده آماده تحویل و نصب روی گوشی شما خواهد بود.

---

## 📲 روش ۲: نصب مستقیم PWA روی گوشی (بدون نیاز به فایل APK)
1. با مرورگر Chrome یا سامسونگ روی گوشی اندروید وارد نشانی https://zqz.ir شوید.
2. روی منوی سه نقطه مرورگر زده و گزینه «افزودن به صفحه اصلی» یا «نصب برنامه» را انتخاب کنید.
3. اندروید به صورت خودکار یک وب‌اپلیکیشن نیتیو (WebAPK) با آیکون اختصاصی و بدون نوار آدرس مرورگر روی گوشی شما نصب می‌کند.

---

## 💻 روش ۳: ساخت سورس کد اندروید با Android Studio
فایل‌های سورس کد پروژه اندروید (شامل `MainActivity.java` و `AndroidManifest.xml`) درون این فایل فشرده موجود است و به راحتی با Android Studio قابل بیلد و انتشار در کافه بازار یا مایکت است.
